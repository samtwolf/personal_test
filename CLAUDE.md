# personal_test

This is the testing repo for the github.com account (samuelwolf2021@gmail.com).

Use this project to test sync and evaluate capabilities for the personal GitHub account, analogous to `projects_github_mit/test_project/` for the MIT GitHub account.

This is a test project used to evaluate GitHub integration with various Claude agents. All work should happen directly on the master branch - no feature branches needed.

Git access: SSH to github.com is served by the 1Password SSH agent (since 2026-09-06); after 1Password locks, the first push needs a one-click approval from its menu-bar icon.
